## *🧪 What's in each write-up*

Every folder contains:
- **Vulnerability overview** — what the bug class is and why it matters
- **Steps to reproduce** — with redacted screenshots (session tokens/cookies blurred)
- **Root cause** — what specifically in the backend logic caused it
- **Impact** — realistic attacker scenario
- **Remediation** — how the issue should actually be fixed

## *📜 Disclaimer*

All PortSwigger labs were completed on PortSwigger's own sandboxed
Web Security Academy environment, explicitly provided for this purpose.
Any real-world testing referenced was conducted against programs with a
published Vulnerability Disclosure Policy, within the defined scope and
rules of engagement.
